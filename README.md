#  Qahwa Café Website

A modern and responsive café website built with React and Vite, featuring an elegant design inspired by the warmth and atmosphere of coffee culture.

##  Live Demo

**[Visit Qahwa Café](https://qahwa-seven-mu.vercel.app/)**

##  Features

- Modern and visually appealing user interface
- Responsive design for desktop, tablet, and mobile devices
- Reusable React components
- Interactive user interface
- Coffee-inspired styling and typography
- Fast development and optimized production build using Vite

##  Technologies Used

- **React** — Building interactive user interfaces
- **Vite** — Development server and build tool
- **JavaScript** — Application logic and interactivity
- **CSS3** — Styling and responsive layouts
- **HTML5** — Website structure
- **Vercel** — Deployment and hosting

##  Getting Started

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd qahwa-react
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

##  Build for Production

To create an optimized production build, run:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```

##  Deployment

The website is deployed on Vercel.
